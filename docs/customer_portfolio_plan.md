## Ограничения данных

- `mart.customer_monthly` содержит 6 полей: `month_date`, `customer_key`, `sales`, `profit`, `sales_30plus`, `profit_30plus` (последние два — с 16.11.2026, шаг 1). Нет числа заказов, скидки по группам кроме 30%+ и страны.
- Проблема 2 без расширения MART мерой не показывалась → вариант A (выполнен, шаг 1).
- Каждый `customer_key` относится ровно к одной стране и одному рынку (проверено для всех 17 415 клиентов, `q2.py`). Customer ID фактически означает «клиент в стране»: «новый» клиент может быть известным покупателем, впервые купившим в другой стране.
- «Новые / возвращающиеся» требуют истории: за 2012 год все клиенты новые → мера выводит «unavailable», как при отсутствии PY.
- Число заказов клиента недоступно; «месяцев с покупками» — замена только для анализа, на странице не используется.
- Статусы и количества клиентов неаддитивны: на квартале, годе и итоге пересчитываются по сумме Profit клиента за выбранный период (`analysis/mart_customer_design.txt`, разделы 4–5).

## Решения (16.11.2026)

1. Все 6 проблем остаются на странице.
2. **Вариант A:** добавить в `mart.customer_monthly` столбцы `sales_30plus` / `profit_30plus` по образцу шага 1a Product Portfolio (`mart.geographic_monthly`, коммит `916c42c`): суммы строк заказа со скидкой > 0,30 за месяц × клиент, без таких строк 0. Выполнено 16.11.2026 (шаг 1).
3. Страну в `dim_customer` не добавляем: география показана на Market Performance.
4. Таблицу «Top-N клиентов» не делаем: 87% клиентов покупали в одном месяце, список почти совпадал бы со списком убыточных заказов.

## Черновик страницы (уточняется после шага 1)

- **Заголовок и слайсеры** — как на Product Portfolio: Year (по умолчанию 2015), Quarter, Segment (`dwh dim_customer[segment]`) на месте Category.
- **4 KPI:** Customers (подпись YoY %), Unprofitable Customers (подпись — доля, %), Profit per Customer (подпись Δ PY), Net Loss in Unprofitable Customers.
- **Business Insights, 3 карточки** (нейтральные факты, деньги в K): новые и возвращающиеся (число, маржа); удержание к PY (сколько клиентов PY вернулось, сколько убыточных PY снова убыточны); доля убытка убыточных клиентов от строк 30%+ (после шага 1).
- **Панель «Customer Size Bands»** — столбцы по диапазонам Sales клиента (< 100, 100–500, 500–1K, 1K–2,5K, ≥ 2,5K): клиенты, Profit, маржа. Диапазоны — отдельная таблица без связей + мера (статус и диапазон считаются динамически, не calculated column).
- **Панель «Profit Trend by Customer Cohort»** — помесячная прибыль прибыльных и убыточных клиентов, состав групп по всему выбранному периоду (`mart_customer_design.txt`, раздел 5).
- **Матрица Segment → New / Returning** — клиенты, доля убыточных, маржа, Δ PY.
- Подзаголовок со ссылкой: «By country: Market Performance».

### Шаг 6: взаимодействия визуалов (19.11.2026)

До шага 6 в `page.json` не было `visualInteractions`, везде действовало поведение по умолчанию: столбчатая диаграмма Size Bands (`…a619`) получала **highlight**, остальные визуалы — **filter**. Highlight на панели долей рисует долю внутри выборки (месяц или сегмент) поверх долей за весь период: две несопоставимые картины на одной оси. Решение пользователя: `…a623` (Cohort, клик по месяцу) → `…a619` и `…a627` (матрица) → `…a619` — **filter** (`DataFilter`). Остальные пары оставлены по умолчанию; KPI и Business Insights реагируют на клики, как на Product Portfolio.

#### Известные ограничения взаимодействий

- **Клик по строке New / Returning в матрице** (`…a627`) фильтрует KPI-карточки, Business Insights, линии Cohort и панель Size Bands **только по сегменту**. `Customer Type` — таблица без связей; её фильтр учитывают только меры `Cust Type *`. Например, клик по «Consumer → New» покажет в KPI всех клиентов Consumer, а не новых. Настройками взаимодействий это не разделить (источник один — матрица); исправление потребовало бы переписать меры KPI и Insights под `Customer Type`. Не меняем.
- **Клик по столбцу Size Bands** (`…a619`) не меняет другие визуалы. `Customer Size Band` — таблица без связей; её фильтр учитывают только меры `Cust Band *`. Формально взаимодействие — filter, но ни одна цифра на странице не меняется, выделяется только сам столбец. Не меняем.
